# Smart Organ Transplant Matching & Secure Hospital Coordination System

A full-stack healthcare platform that automates donor-recipient matching and enables secure coordination between hospitals for efficient and transparent organ allocation.

---

## Project Overview

The Smart Organ Transplant Matching System is designed to simplify the organ transplant process by securely managing donor and recipient information, performing compatibility matching, and coordinating transplant requests between hospitals through a centralized platform.

---

## Features

- Donor and Recipient Registration
- Automated Organ Matching
- Secure Hospital Coordination
- User Authentication and Authorization
- Centralized Patient & Organ Database
- Real-Time Matching Dashboard

---

## Tech Stack

- **Frontend:** React.js, Vite, HTML, CSS, JavaScript
- **Backend:** Python
- **Matching Engine:** C (AVL Tree, Heap, Graph, Segment Tree)
- **Database:** MySQL

---

## Algorithms Used

- AVL Tree for efficient donor and recipient management.
- Heap for priority-based organ allocation.
- Graph algorithms for hospital coordination.
- Segment Tree for optimized matching queries.

## How It Works

1. Hospitals register donors and recipients.
2. The system stores patient details securely.
3. The matching engine identifies compatible donor-recipient pairs.
4. Hospitals coordinate organ allocation through a centralized dashboard.
5. The transplant status is updated and tracked in real time.

## Installation

```bash
# Clone the repository
git clone https://github.com/siddhi10906/Smart-Organ-Transplant-Matching-System.git

# Go to project folder
cd Smart-Organ-Transplant-Matching-System

# Frontend
cd frontend
npm install
npm run dev

# Backend
cd ../backend
pip install -r requirements.txt
python app.py
```
